Hilfe und FAQ

Antworten auf häufige Fragen.

Einrichtung

Welches Gerät eignet sich als Heimserver?

Jedes Gerät, das dauerhaft eingeschaltet bleibt und genug Speicherplatz hat: ein älterer PC, ein Mini-PC oder ein NAS mit Docker.

Muss der Heimserver aus dem Internet erreichbar sein?

Nur, wenn Ihre Geräte auch unterwegs synchronisieren sollen. Holvana führt Sie dabei durch die Einrichtung. Achten Sie auf aktuelle Updates Ihres Routers und Servers.

Wie verbinde ich ein neues Gerät?

Öffnen Sie am Heimserver „Geräte → Neues Gerät verbinden“. Geben Sie den angezeigten Code auf dem neuen Gerät ein. Der Code gilt zehn Minuten.

Synchronisation und Wiederherstellung

Wie stelle ich eine gelöschte Datei wieder her?

Öffnen Sie „Versionsverlauf“, wählen Sie den Ordner und die Datei und klicken Sie bei der gewünschten Fassung auf „Wiederherstellen“.

Was passiert bei gleichzeitigen Änderungen?

Holvana behält beide Fassungen und zeigt einen Konflikt an. Sie entscheiden, welche Fassung gilt.

Ersetzt Holvana ein Backup?

Nein. Eine Löschung kann auf alle Geräte übertragen werden. Der Versionsverlauf hilft in vielen Fällen, ersetzt aber keine Sicherung auf einem getrennten Datenträger.

Kauf und Lizenz

Wie erhalte ich meinen Lizenzschlüssel?

Direkt nach dem Kauf auf der Bestellbestätigung und per E-Mail.

Kann ich die Lizenz auf einen neuen Computer übertragen?

Ja. Melden Sie das alte Gerät unter „Einstellungen → Lizenz“ ab und geben Sie den Schlüssel auf dem neuen Gerät ein.

Welche Zahlungsarten gibt es?

Kreditkarte und Banküberweisung. In diesem Studienprojekt werden keine Zahlungen abgewickelt.

Keine Antwort gefunden?

Schreiben Sie uns. Wir antworten in der Regel innerhalb von zwei Werktagen.
