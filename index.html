Funktionen

Was Holvana für Sie erledigt

Drei Aufgaben, die im Alltag mit mehreren Geräten immer wieder anfallen.

Synchronisieren

Änderungen an einer Datei erscheinen automatisch auf allen verbundenen Geräten. Die Geräte verbinden sich direkt miteinander (Peer-to-Peer).

Wiederherstellen

Versehentlich gelöschte oder überschriebene Dateien holen Sie mit wenigen Klicks aus dem Versionsverlauf zurück.

Version auswählen

Wurde eine Datei auf zwei Geräten gleichzeitig geändert, entscheiden Sie, welche Fassung gilt. Keine Version geht verloren.

In vier Schritten

So richten Sie Holvana ein

  1. Server installieren

    Installieren Sie Holvana auf einem Gerät, das immer eingeschaltet ist, zum Beispiel einem alten PC oder einem NAS.

  2. Geräte verbinden

    Installieren Sie Holvana auf Laptop und Smartphone und verbinden Sie sie mit einem einmaligen Code.

  3. Ordner wählen

    Legen Sie fest, welche Ordner auf welchen Geräten synchronisiert werden.

  4. Fertig

    Holvana arbeitet im Hintergrund. Sie können jederzeit ältere Versionen wiederherstellen.

Warum Holvana

Ihre Daten verlassen Ihr Zuhause nicht

Viele Synchronisationsdienste speichern Ihre Dateien auf Servern eines Anbieters. Bei Holvana ist der Server Ihr eigenes Gerät.

  • Keine Speichergebühren und keine Kontingente eines Anbieters
  • Verschlüsselte Verbindungen zwischen Ihren Geräten
  • Holvana GmbH hat keinen Zugriff auf Ihre Dateien

Häufige Fragen

Kurz beantwortet

Brauche ich einen eigenen Server?

Sie brauchen ein Gerät, das möglichst immer eingeschaltet ist. Das kann ein alter PC, ein Mini-PC oder ein NAS sein. Ohne ein solches Gerät synchronisieren Ihre Geräte nur, wenn sie gleichzeitig online sind.

Ersetzt Holvana ein Backup?

Nein. Der Versionsverlauf hilft bei versehentlich gelöschten Dateien. Er ersetzt keine Sicherung auf einem getrennten Datenträger. Wir empfehlen zusätzlich regelmäßige Backups.

Muss ich für Updates bezahlen?

Sicherheitsupdates sind im Kaufpreis enthalten. Neue Hauptversionen (zum Beispiel von Version 1 auf 2) erhalten bestehende Kundinnen und Kunden zu einem reduzierten Upgrade-Preis.
