Funktionen

Was Holvana kann

Automatische Synchronisation

Ausgewählte Ordner werden zwischen allen verbundenen Geräten abgeglichen. Geänderte Teile einer Datei werden einzeln übertragen.

Gelöschte Dateien wiederherstellen

Gelöschte und überschriebene Dateien bleiben am Heimserver im Versionsverlauf erhalten und lassen sich zurückholen.

Konflikte selbst entscheiden

Ändern zwei Geräte dieselbe Datei gleichzeitig, bleiben beide Fassungen erhalten. Sie wählen, welche gilt.

Verschlüsselte Verbindungen

Geräte verbinden sich nur nach Bestätigung durch einen Code. Die Übertragung zwischen den Geräten ist verschlüsselt.

Selbst gehostet

Ihr eigener Server ist ein „immer eingeschalteter Peer“. Holvana GmbH betreibt keine Server für Ihre Dateien.

Einmal kaufen

Kein Abo. Sicherheitsupdates sind enthalten, neue Hauptversionen gibt es zum reduzierten Upgrade-Preis.

Technik

So funktioniert Holvana

Holvana besteht aus einem Programm, das auf jedem Ihrer Geräte läuft. Eines davon, Ihr Heimserver, bleibt immer eingeschaltet. Aus Sicht der anderen Geräte ist er einfach ein Gerät, das nie schläft.

Ist der Laptop unterwegs, holt er sich Änderungen beim nächsten Kontakt vom Heimserver. Die Geräte sprechen direkt miteinander (Peer-to-Peer). Eine zentrale Cloud gibt es nicht.
